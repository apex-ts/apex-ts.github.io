APEX TS WEBSITE
================
نسخه ساخته‌شده: PHP + MySQL

1) فایل schema.sql را داخل دیتابیس MySQL اجرا کنید.
2) config.php مشخصات دیتابیس و حساب ادمین را دارد.
3) صفحه اصلی: index.php
4) ورود/ثبت‌نام: login.php
5) پنل ادمین: admin.php

امنیت:
- رمز کاربران با password_hash ذخیره می‌شود و قابل مشاهده/بازیابی به صورت متن ساده نیست.
- پنل ادمین فقط مدیریت کاربران و حذف نظرات را انجام می‌دهد.
- برای استقرار عمومی حتماً HTTPS فعال کنید و پس از تحویل، رمز دیتابیس و رمز ادمین را عوض کنید.
