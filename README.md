# NASLE20 — نسل۲۰
پروژه Next.js + React + TypeScript، فارسی RTL، طراحی سبز روشن/سفید/طلایی، بدون هیچ پایگاه داده‌ای.

## نصب و اجرا
1. Node.js نسخه 18.17 یا بالاتر نصب کن.
2. در پوشه پروژه `npm install` اجرا کن.
3. `.env.example` را به `.env` کپی کن و `ADMIN_USERNAME`، `ADMIN_PASSWORD` و `SESSION_SECRET` را مقدار بده. SESSION_SECRET حداقل ۳۲ کاراکتر تصادفی باشد.
4. `npm run dev` را اجرا کن؛ سایت روی http://localhost:3000 و پنل روی http://localhost:3000/admin است.
5. برای استقرار: `npm run build` و سپس `npm start` روی هاست Node با فایل‌سیستم پایدار.

## موجود در این نسخه
- صفحه اصلی واکنش‌گرا، دوره/کتاب/پادکست و FAQ
- محتوای seed در `data/content.json` و API خواندن
- پنل مدیر با ورود رمز از متغیر محیطی، افزودن محتوا و آپلود فایل از دستگاه
- اعتبارسنجی پسوند، MIME و سقف ۲۵۰MB برای آپلود
- مسیر محتوای مستقل و نمایش قیمت
- بدون SQL/NoSQL، ORM، migration یا پایگاه داده

## محدودیت‌ها را جدی بگیر
این یک پایه اجرایی قابل توسعه است، نه سامانه تجاری آماده تولید:
- JSON فقط روی سرور Node با فایل‌سیستم پایدار مناسب است؛ روی GitHub Pages یا محیط serverless با فایل‌سیستم موقت ذخیره دائمی نیست. چند نوشتن هم‌زمان ممکن است به قفل/صف نیاز داشته باشد.
- آپلود فعلی محلی و خصوصی در `private_uploads` است. اتصال Cloudflare R2/S3 هنوز پیاده‌سازی نشده و فایل آپلودشده خودکار به محصول متصل نمی‌شود. برای استقرار عمومی باید adapter R2/S3 و URL امضاشده/endpoint دانلود با کنترل مجوز اضافه شود.
- ورود پیامکی عمداً غیرفعال است؛ SMS واقعی و ذخیره امن OTP/محدودسازی درخواست‌ها باید پیاده‌سازی شود. هیچ کد نمایشی یا ورود جعلی تولید نمی‌شود.
- پرداخت واقعی متصل نیست؛ هیچ سفارش یا پرداختی به‌صورت جعلی موفق نمی‌شود.
- پنل فعلاً افزودن محتوا و آپلود دارد؛ ویرایش/حذف کامل، مدیریت جلسات دوره، مدیریت کاربران و علاقه‌مندی‌ها هنوز تکمیل نشده‌اند.
- قبل از عمومی‌کردن، CSRF کامل، rate limiting، audit log، ذخیره‌سازی پایدار و بررسی امنیتی اضافه کن. `.env` را به GitHub نفرست.
- محتوای سلامت روان آموزشی است و جایگزین تشخیص یا درمان تخصصی نیست.
